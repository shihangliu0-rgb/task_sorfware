# DevLog · 开发工作日志

一个**本地桌面软件**，用来记录「我现在在干什么、有哪些任务没做完、遇到了什么问题」。

双击启动后会弹出一个独立窗口（没有浏览器地址栏，就是一个正常的桌面应用）。
所有数据存在你自己电脑上，**不联网也能完整使用**。

---

## 快速开始

**Windows**：双击 `启动DevLog.bat`
**macOS**：双击 `启动DevLog.command`
**Linux / 终端**：`./start.sh`

只要电脑上有 Python 3.9+ 就能跑，**不需要安装任何第三方库**。

> 首次在 macOS 双击 `.command` 如果提示"无法打开"，右键 → 打开 → 确认一次即可。

## 九个功能

### 🎯 当前任务
首页一眼看清今天的状态：进行中 / 待办 / 受阻 / 今日完成 / 未解决问题 / 今日错误数 / 专注时长 / 提交次数。
左下角有个**计时器**，选中任务点「开始」，停止时自动累计专注时间。

### 📋 任务清单
增删改查、四种状态（待办 / 进行中 / 受阻 / 已完成）、三级优先级、项目、标签、关联分支。
点任务上的 🎯 设为"当前任务"，之后记的笔记、截图、日志都会自动挂到它名下。

### 🐛 问题列表
专门记"卡住我的东西"：严重程度分四级（阻塞 / 高 / 普通 / 低），可以关联到具体任务，
解决后填写解决方案存档，下次遇到同样的坑能翻出来。

### 📊 日志分析（核心）
把报错、终端输出、服务日志**直接粘贴进去**，自动：

- **识别错误级别** —— 优先读 `ERROR`/`WARN` 显式标记，没有标记时用关键词启发式判断
- **整块吞掉堆栈** —— Python traceback 会合并成一条，只显示最关键的异常行
- **归并同类错误** —— 把时间戳、端口号、内存地址、UUID、路径等变量抹掉后做指纹，
  `Connection refused to db:5432` 和 `db:5999` 会自动归为同一类，显示 `×2`
- **给出排查建议** —— 内置 14 类常见错误的判断规则（缺依赖、端口占用、空指针、
  超时、OOM、跨域、权限、数据库约束冲突……），命中后直接告诉你往哪查
- **一键存为问题** —— 分析结果里点按钮就能转成问题记录

也支持直接读日志文件：填个路径点「读取文件」。

### 🕒 时间线
所有活动按时间倒序排列，按天分组。任务变更、问题记录、代码提交、日志导入、
截图、专注时段、随手笔记全在一条线上，可按类型筛选。**回答"我今天到底干了啥"最快的地方。**

### 🖼 图片附件
**Ctrl+V 直接粘贴截图**（这是最常用的方式），也支持拖拽和选择文件。
图片存在本地，点击可放大查看，自动关联到当前任务。

### 🌿 Git 关联

**它解决什么问题**：写周报时你经常想不起来"这个任务我到底改了哪些代码"。
这个功能把你的 commit 自动认领到对应任务上，日报里就会自动出现
「📦 代码提交（3 次，+214/-6）」并标明属于哪个任务。

**怎么用**：

1. 打开左侧「🌿 Git 关联」
2. 填入项目文件夹路径 —— 就是包含 `.git` 的那个目录
   （Windows 如 `D:\projects\myapp`，Mac 如 `/Users/你/code/myapp`）
3. 点「同步提交」，完成

之后每天点一次同步就行；装了 VSCode 插件的话，命令面板里搜 `DevLog: 同步当前仓库提交` 更快。

**三种自动认领方式**（满足任意一种即可）：

| 方式 | 怎么做 | 准确度 |
|---|---|---|
| 写编号 | 提交信息里带 `#3`，如 `fix: 修复登录 #3` | ⭐ 最准，推荐 |
| 绑分支 | 任务里填「关联分支」`feat/pay`，该分支的提交自动归它 | 准 |
| 猜关键词 | 提交信息和任务标题词汇重合度够高时自动匹配 | 兜底 |

没认领上的提交也会照常记录，只是不挂在任务名下，不影响使用。

**会读取所有分支**，所以你切到别的分支干活时，提交一样不会漏。
页面上还会显示当前分支和工作区有几个文件没提交。

> 只读操作 —— 只会执行 `git log` / `git status`，绝不会修改你的仓库。

### ⌨️ 快捷键记录
点输入框**直接按组合键就能自动捕获**，记下作用和所属软件。
按使用次数排序，点 👍 计一次数——用得多的自然排前面，慢慢就记住了。

### 🤖 AI 总结
一键生成日报/周报，自动汇总：完成了什么、还剩什么、卡在哪、代码提交、
日志暴露的风险、以及**下一步最该做的几件事**。可复制或导出 `.md`。

**默认用内置的离线规则引擎，不联网、不需要任何 API Key。**
如果想要更自然的文字，在「设置」里填入兼容 OpenAI 接口的 Key 即可切换成大模型总结
（调用失败会自动退回离线模式，不会卡住）。

## 快捷键

| 按键 | 作用 |
|---|---|
| `Ctrl` + `K` | 命令面板（也能搜任务和问题） |
| `Ctrl` + `N` | 新建任务 |
| `Ctrl` + `L` | 跳到日志分析 |
| `Ctrl` + `V` | 粘贴截图存为附件 |
| `Ctrl` + `Enter` | 保存当前输入框 |
| `1` … `9` | 切换左侧页面 |
| `Esc` | 关闭弹窗 |

## VSCode 插件（可选）

`vscode-extension/` 目录里有配套插件，装上之后可以在编辑器里：

- 选中报错 → 右键存为问题（自动附上文件名和行号）
- 选中日志 → 右键分析，结果开在侧栏
- `Ctrl+Alt+N` 快速记一笔
- 状态栏实时显示待办数和未解决问题数，点击可切换当前任务

安装方式见 [`vscode-extension/README.md`](vscode-extension/README.md)。

## 数据存在哪

默认在 `~/.devlog/`：

```
~/.devlog/
├── devlog.db        SQLite 数据库（任务、问题、日志、时间线…）
└── attachments/     图片附件原文件
```

**直接备份这个目录就能迁移到另一台电脑。** 想换位置就设环境变量 `DEVLOG_HOME`。

---

## 命令行用法

```bash
python3 -m devlog                  # 正常启动（开窗口）
python3 -m devlog --no-window      # 只起服务，不开窗口
python3 -m devlog --port 9000      # 指定端口（被占用会自动往后找）
```

## 技术说明

- **后端**：Python 3.9+ 标准库，零第三方依赖，SQLite 存储
- **前端**：原生 HTML/CSS/JS，无框架，深色/浅色主题
- **窗口**：调用系统里的 Chrome/Edge 以 `--app` 模式打开，没有则退回默认浏览器
- **安全**：服务只监听 `127.0.0.1`，拒绝跨站请求，静态文件和附件都做了路径穿越防护
