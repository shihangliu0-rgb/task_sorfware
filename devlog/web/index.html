🌿 本地仓库

把你写的代码提交自动认领到对应任务上，生成日报时就能列出「这个任务今天写了哪些代码」。 填入项目文件夹路径（就是含 .git 的那个目录），点同步即可。

填到 .git 或子目录也没关系，会自动纠正到项目根目录。 只读取，绝不会修改你的仓库。

三种自动认领方式（满足任意一种即可）：
1️⃣ 提交信息里写 #任务编号，如 fix: 修复登录 #3 ← 最准，推荐
2️⃣ 任务里填了「关联分支」，该分支上的提交自动归它
3️⃣ 提交信息和任务标题关键词重合度高时自动猜
没认领上的提交也会记录，只是不挂在任务下。

💾 我的数据存在哪

所有任务、问题、日志、截图都保存在你自己电脑的这个目录里：

~/.devlog/
├── devlog.db　　　 任务、问题、日志、时间线
└── attachments/　　图片附件原文件
数据不在代码仓库里，也不会被 git 提交。
所以重新 clone 仓库时，本机数据会照常保留； git push 也不会把你的工作记录传到 GitHub 上。
换电脑想带走数据：直接复制上面这个文件夹即可。
